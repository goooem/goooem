## 🎧 Обо мне

Я проектирую детерминированное микропрограммное обеспечение, конвейеры жесткого реального времени для обработки звука и граничные сенсорные узлы. Большая часть моего времени уходит на вычисление соотношения сигнал/шум, оптимизацию векторных инструкций ARM NEON и отладку протоколов SPI/I2S с помощью логических анализаторов.

- 🔭 **Основная работа**: Ведущий архитектор прошивок в проекте распределенных акустических гидрофонов для морской биоакустики.
- ⚙️ **Open Source**: Создание аудио-примитивов DSP без динамического выделения памяти (Zero-allocation), прошивок для модульных синтезаторов и низкоджиттерных драйверов Linux.
- 🪵 **Окружение**: Arch Linux, Neovim, Saleae Logic, паяльная станция и стопка сервисных мануалов Roland 1970–80-х годов.
- 💬 **Темы для обсуждения**: Безаллокационные кольцевые буферы, фазовые искажения фильтров, арифметика с фиксированной точкой Q31 и схемотехника Eurorack.

## 🛠️ Текущие исследования и фокус

- **Субмиллисекундные аудио-буферы**: Проектирование неблокирующих SPSC-буферов (один производитель, один потребитель) с гарантированным ограниченным временем выполнения на асимметричных многоядерных SoC.
- **Микромощные гидрофонные решетки**: Разработка bare-metal прошивок для автономных морских буев с солнечным питанием, передающих акустические метаданные через спутниковые каналы с низкой пропускной способностью (Iridium SBD).
- **Встроенный аудиосинтез**: Модернизация классических алгоритмов таблично-волнового (wavetable) синтеза с использованием SIMD-интерполяции на современных микроконтроллерах.

## 📦 Избранные Open Source проекты

### [poly-phase](https://github.com/goooem/poly-phase)
*Заголовочный полифазный FIR-ресемплер на C++20 с аппаратным SIMD-ускорением.*
- Нулевое выделение памяти в куче во время выполнения после фазы инициализации.
- Векторизованные реализации для AVX2, ARM NEON и переносимый резервный вариант.
- Подавление в полосе задерживания линейной фазы > 110 дБ во всем слышимом диапазоне.

### [whisper-dsp](https://github.com/goooem/whisper-dsp)
*Bare-metal библиотека цифровой обработки сигналов для микроконтроллеров ARM Cortex-M.*
- Каскады биквадратных фильтров с фиксированной точкой Q15 и Q31.
- Оконные процедуры БПФ реального времени с детерминированным числом тактов.
- Оптимизирована для энергоэффективного обнаружения акустических аномалий на периферийных устройствах.

### [seafloor-stream](https://github.com/goooem/seafloor-stream)
*Отказоустойчивый демон подводной акустической телеметрии на безопасном `no_std` Rust.*
- Работает в условиях нестабильных каналов связи акустических модемов и спутников.
- Уплотнение очереди приоритетов исключает переполнение буфера при разрыве соединения.
- Полный набор модульных тестов, выполняемых на виртуальном оборудовании в QEMU.

### [knob-os](https://github.com/goooem/knob-os)
*Открытая прошивка тактильного поворотного энкодера для музыкантов и саунд-дизайнеров.*
- Замкнутый контур управления магнитным энкодером со сглаживанием скорости по ПИД-закону.
- Нативная поддержка протокола высокоточного обмена параметрами USB MIDI 2.0 Property Exchange.
- Настраиваемые виртуальные щелчки (detents), механические упоры и эмуляция упругого возврата.

## 📐 Инженерное кредо

```
1. Каждый выделенный байт обязан оправдать свое нахождение в оперативной памяти.
2. Джиттер опаснее задержки: предсказуемость превыше всего.
3. Если процесс нельзя измерить осциллографом или perf, это лишь догадка.
4. Принципиальная схема, исходный код и механические допуски должны говорить об одном и том же.
5. Простая схема с выверенной прошивкой долговечнее перегруженных управляющих структур.
```
