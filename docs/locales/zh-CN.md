## 🎧 关于我

我专注于设计确定性固件、硬实时音频处理管线以及边缘传感节点。我的日常工作大多是分析信噪比、榨取 ARM NEON 向量指令的计算周期，以及使用逻辑分析仪调试 SPI/I2S 硬件总线。

- 🔭 **主职工作**: 资深固件架构师，负责研发用于海洋生物声学监测的分布式水下声学传感水听器。
- ⚙️ **开源项目**: 构建零堆内存分配（Zero-allocation）音频 DSP 原语、模块化合成器固件与超低抖动 Linux 驱动。
- 🪵 **工作环境**: Arch Linux、Neovim、Saleae 逻辑分析仪、恒温焊台，以及案头上一摞复古 Roland 设备维修手册。
- 💬 **常聊话题**: 零分配环形缓冲区、滤波器相位失真、定点 Q31 数学运算与 Eurorack 模拟电路拓扑结构。

## 🛠️ 当前研究与专注方向

- **亚毫秒级音频缓冲区**: 在非对称异构多核 SoC 上设计具备确定性有限执行时间保障的无锁单生产单消费（SPSC）环形缓冲区。
- **超低功耗水听器阵列**: 为太阳能/电池供电的海洋浮标编写裸机固件，通过超低带宽卫星链路（Iridium SBD）实时回传声学特征元数据。
- **嵌入式音频合成**: 借助现代微控制器上的 SIMD 加速插值算法，对经典的复古波表合成架构进行现代化重构。

## 📦 代表性开源项目

### [poly-phase](https://github.com/goooem/poly-phase)
*基于 C++20 的单头文件、SIMD 硬件加速多相（Polyphase）FIR 重采样库。*
- 初始化后运行时堆内存零动态分配。
- 涵盖 AVX2、ARM NEON 原生优化及高通用性回退实现。
- 全可听频段内线性相位阻带衰减抑制比 > 110 dB。

### [whisper-dsp](https://github.com/goooem/whisper-dsp)
*针对 ARM Cortex-M 微控制器深度定制的裸机数字信号处理函数库。*
- 定点 Q15 与 Q31 双二阶（Biquad）IIR 级联滤波器。
- 保证精确执行时钟周期的实时加窗快速傅里叶变换（FFT）程序。
- 专为能耗极度受限的边缘声学异常事件触发检测而优化。

### [seafloor-stream](https://github.com/goooem/seafloor-stream)
*使用纯安全 `no_std` Rust 开发的高抗损水下声学遥测守护进程。*
- 专门应对高丢包率、断续的水下声学调制解调器与卫星通信链路。
- 内置带优先级的内存队列紧缩机制，彻底杜绝通讯黑障期的缓冲区溢出。
- 配备可在 QEMU 模拟芯片环境中闭环运行的高覆盖率单元测试集。

### [knob-os](https://github.com/goooem/knob-os)
*面向音乐创作者与声音设计师的开源触觉旋钮控制器固件。*
- 结合 PID 速度平滑滤波算法的闭环磁编码器动力反馈。
- 原生支持 USB MIDI 2.0 高精度属性交换（Property Exchange）协议规范。
- 允许自由配置虚拟步进阻尼感、硬物理限位点与弹性回弹阻尼模拟。

## 📐 工程信条

```
1. 每一字节被分配的内存，都必须证明其常驻系统的不可替代性。
2. 时钟抖动远比时延更为致命；系统的可预测性高于一切。
3. 如果一项特性无法被示波器或 perf 性能分析器量化，它就只是臆测。
4. 原理图、固件源码与机械装配公差，必须始终叙述同一种事实。
5. 带有考究固件的极简纯粹电路，其生命力远胜于臃肿庞杂的状态机。
```
